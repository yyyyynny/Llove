## ① 합성어 붙임표(-) 때문에 정상 단어가 "없는 단어"가 됩니다 — 가장 시급

우리말샘은 **합성어 표제어에 붙임표를 넣어** 등재합니다. 그런데 Worker가 이 붙임표를
제거하지 않고 정확 일치로 비교해서, 사용자가 붙여 쓴 정상 단어가 전부 거부됩니다.

이 환경에서 Worker에 직접 질의한 결과입니다:

| 보낸 값 | 응답 | | 보낸 값 | 응답 |
|---|---|---|---|---|
| `가마솥` | 존재 **false** | | `가마-솥` | 존재 **true** (뜻풀이 1건) |
| `뽕나무` | 존재 **false** | | `뽕-나무` | 존재 **true** (뜻풀이 2건) |
| `눈사람` | 존재 **false** | | `나무`·`학교`·`무지개` | 존재 true |

마지막 줄이 대조군입니다 — 합성어가 아니라 표제어에 붙임표가 없는 단어는 정상 동작합니다.
관리자님이 보내주신 스크린샷(가마솥·뽕나무·뽕잎 오답)의 원인이 정확히 이것입니다.

**고칠 부분**: API 응답의 `word` 필드를 비교하기 전에 정규화하세요.

```js
const 정규화 = w => String(w).replace(/[-^]/g, '').trim();
// 비교: 정규화(item.word) === 정규화(요청단어)
```

`^`도 함께 지워야 합니다(우리말샘은 띄어 쓰는 합성어를 `가마솥^밥`처럼 표기합니다).

> **임시 대응은 이미 넣어 뒀습니다.** 클라이언트가 붙임표를 가능한 위치에 끼워 재조회합니다
> (`wchain/js/국어원.js`의 `붙임표_변형`). 다만 단어당 최대 5회 추가 호출이 발생하므로,
> Worker가 고쳐지면 이 폴백은 걷어내는 편이 좋습니다.

## ② 후보 목록이 너무 적습니다 — 게임이 5수 만에 막힙니다

`{글자, 방향}` 조회로 받는 후보 개수 실측:

| 글자 | 후보 수 | 실제 내용 |
|---|---|---|
| 가 | 10개 | 가가, 가가득제, 가가린, 가가미이시, 가가비… |
| 무 | 8개 | 무가, 무가당, 무가지보, 무각… |
| **사** | **2개** | 사가, 사가망처 |

우리말샘에 '사'로 시작하는 단어는 수천 개인데 2개만 옵니다. 원인 두 가지로 보입니다:

1. **첫 페이지(10건)만 가져옴** — `num` 파라미터가 기본값
2. **붙임표가 든 표제어를 걸러서 버림** — '사'의 경우 10건 중 8건이 합성어라 2개만 남음

이 상태로 실제 판을 돌려 보면 **5수 만에 이을 단어가 없어 막힙니다.**
게임이 우리말샘에 전적으로 기대게 된 지금(내부 사전 폐지) 이건 치명적입니다.

**고칠 부분**:
- `num=100` 정도로 늘리고, 필요하면 `start`로 2~3페이지까지 받으세요.
- 붙임표가 든 항목을 **버리지 말고 정규화해서** 보내세요(①의 정규화 함수 재사용).
  지금은 합성어가 통째로 후보에서 사라져, 가장 흔한 단어들이 게임에 안 나옵니다.
- 공백이 든 구(句)·1글자 항목을 거르는 기존 처리는 그대로 두셔도 됩니다.

## ③ 표제어 순서상 앞쪽만 와서 희귀어만 나옵니다

②를 고치면 대부분 해소되지만, 정렬이 표제어순이라 앞쪽에 희귀어·고유명사가 몰립니다
(스가랴·스굼푸·스까락…). 관리자님이 "심연도 희귀어가 별로 안 나온다"고 하셨던 것과
반대로, 지금은 **낮은 난이도에도 희귀어만** 나올 수 있는 구조입니다.

**선택지**(급하지 않음):
- 우리말샘 API의 정렬 옵션(`sort=popular` 등)이 있으면 그걸 쓰거나,
- 후보를 넉넉히 받아 Worker에서 섞어 보내면 클라이언트의 난이도 슬라이스가 제대로 작동합니다.

클라이언트는 이미 "표제어 순 앞쪽 = 흔한 말"을 전제로 난이도를 나누고 있습니다
(`난이도_슬라이스` — 안온 40% / 격동 70% / 초월·심연 100%). ②를 고치면 이 전제가 성립합니다.

## 확인 방법

수정 후 아래를 실행해 세 값이 모두 기대대로 나오면 됩니다.

```bash
# ① 붙임표 — true 가 나와야 함
curl -s -X POST https://urimalsaem-llove.hypoqwer.workers.dev/ \
  -H 'Content-Type: application/json' -d '{"단어":"가마솥"}'

# ② 후보 개수 — 수십~수백 개가 나와야 함
curl -s -X POST https://urimalsaem-llove.hypoqwer.workers.dev/ \
  -H 'Content-Type: application/json' -d '{"글자":"사","방향":"start"}'
```

게임 화면에서도 바로 보입니다 — AI 턴마다 `🌐 우리말샘 후보 N개를 사용합니다`가 로그에 뜨고,
N이 3 이하면 `곧 막힐 수 있습니다` 경고로 바뀝니다.
