# 별바다 세계 (wchain) — 시스템 문서

> 끝말잇기 게임(코드네임: 별바다 세계)의 설계·이식·게이트 정책 문서.
> Llove의 `언어_SYSTEM_v5.md`·`CLAUDE.md`에 대응하는 wchain 전용 지침.
> 다음 세션은 이 문서 + 루트 `/root/.claude/plans/sunny-tickling-heron.md`를 먼저 읽고 이어갈 것.
> 최고 관리자: 성재훈 / 최종 업데이트: 2026-07-19 (Phase 1 착수)

## 1. 개요

파이썬 터미널 게임 `K-WordChain · Dark Fantasy Edition v2.2`(원본 2003줄)를 Llove와 연결되는
**웹(JS) 이세계**로 이식한 프로젝트. Llove = "학습 세계", 끝말잇기 = "별바다 세계"(게임 차원).
같은 사람(구글 계정)이 두 세계를 오간다. 원신의 "같은 여행자, 다른 나라" 구조.

- **배치**: 학습 모드 "밖". Llove 홈(`index.html` `#sh` → `.hh-top`) 우측에 조건부 포탈 아이콘.
- **진입**: 포탈 탭 → 이동 연출 → `wchain/index.html`.
- **로그인**: 같은 GitHub Pages·같은 도메인이라 구글 로그인(Firebase Auth) 자동 공유. 별도 레포·
  별도 Firebase 프로젝트 불필요.

## 2. 저장소 구조

```
wchain/
├── index.html      # 진입점 (Phase 1: 준비 중 placeholder)
├── 시스템.md        # 이 문서
└── (추후) js/·style·자동대조 스크립트 등
```

루트 `index.html`(=Llove)·`js/`·`style.css`·`data/`는 그대로 유지. wchain은 이 하위 폴더에만 격리.

## 3. 해금 — '잇' 회전 퍼즐

포탈은 처음엔 잠겨 있고, **'잇'(끝말잇기의 '잇') 회전 퍼즐**을 풀어야 영구 개방된다.
- '잇' = ㅇ(초성) + ㅣ(중성) + ㅅ(종성). **회전·반전 없는 정방향**을 정답 기준으로 삼는다.
- 조각: **ㅇ → 2조각(좌우 반원)**, **ㅣ → 3조각(세로 3등분)**, **ㅅ → 2조각(두 획 좌/우 대칭)**. 총 7조각.
- 초기엔 각 조각이 90/180/270° 중 무작위로 뒤틀림. 탭/클릭 시 그 조각만 **90° 회전**. 7조각 전부
  0°(정방향)로 맞아 '잇'이 똑바로 읽히면 개방.
- ⚠️ **회전 애니메이션 예외**: Llove `CLAUDE.md`의 "회전 완전 금지" UI 규칙은 화면 전환·장식용
  트랜지션을 겨냥한 것. 이 퍼즐의 90° 회전은 **게임 메커니즘의 본질**이라 wchain 한정으로 허용한다
  (관리자님 확정). Llove 본체 UI는 이 예외를 쓰지 않는다.

### 재잠금 (개방 상태는 Firestore 한글 필드 `별바다개방`에 저장)
1. Llove 학습 데이터 초기화 시
2. 다른 구글 계정 로그인 시 (다른 문서라 자연히 잠김)
3. **wchain 내 게임 데이터 삭제 기능** 실행 시 → **2중 확인 필수**

## 4. 게이트 정책 (Llove의 GROK_활성화 철학 계승 — 전부 기본 false)

| 게이트 | 대상 | 상태 |
|---|---|---|
| `음성생성_활성화` (Llove js/grok.js) | 콜롬비나 음성(RVC/TTS). wchain에서 `음성생성호출()`에 배선만, **켜지 않음** | 봉인 |
| 콜롬비나 페르소나 (제미나이 API) | 대사 톤 포장. 파이썬 엔진(룰 검증)과 완벽 격리, 백도어 전용 (노션 12번) | 봉인 |
| `국어원_활성화` (신설 예정) | 국립국어원 우리말샘 API 단어 검증. Cloudflare Worker 프록시가 인증키 보관 | 봉인 |

**원칙**: 결정론적 게임 엔진(룰 검증·단어 확정)만 먼저 이식·출시. API/음성은 게이트 뒤에서 배선만.
실제 활성화는 서버·키 준비 후 관리자님이 직접 플래그를 켠다.

## 5. 노션 기획 대기 항목 (이식 중 확정)

- **10번 — 오타 페널티 변경**: 잘못된 명령어 입력 시 하트(목숨) 차감 → '실수' 값 누적 방식으로.
  (원본 v2.2는 아직 하트 차감. 이식 시 '실수' 누적으로 교체)
- **11번 — 한방 단어 격리**: 기본 모드에서 한방 단어 사용 시 즉시 패배 처리. 추후 커스텀 설정에서
  허용 여부 옵션 분리.
- **07번 — API 연동 후 아케이드 10층+ 스케일링 해제**: 국어원 API 연동 완료 후 별도 차수에서 논의.

## 6. 이식 규칙·검증

- **모듈 단위 라운드**로 이식(2000줄 한 번에 X). 파이썬 원본 ↔ JS 이식본에 같은 입력을 넣어 출력
  일치를 스크립트로 **자동 대조**(두음법칙·한방 판정 등 입출력 명확한 함수부터).
- 블로킹 `input()` 루프 → 기존 `game_state` 상태 머신을 살린 **이벤트 기반**으로. `time.sleep` →
  `setTimeout`/async, ANSI 색 → CSS.
- 원본 버그도 옮기며 걸러냄(맹목 복사 금지). 완료 후 **오푸스 1회 재검수**로 로직 누락·오역 0건 확인.
- 커밋 케이던스: 약 10구간으로 쪼개 구간마다 커밋·푸시(세션 끊겨도 재개 가능).
