## 2. 발견한 추가 문제 (항목 11 — 사용자 관점 점검)

- **(수정함)** sq2 4지선다/역방향 오답 보기 데이터 부족 → 임시 표본 풀로 보완(주석에 교체 안내).
- **(수정함)** `selAns`는 오답 시 정답 강조를 `onclick` 문자열의 `'true'`로 탐지 → sq2 보기도 boolean으로 전달해 호환.
- **(기록)** `data/` 모드 DB JSON 6종이 빈 파일 → 4지선다·복습 등 풀이 빈약. 데이터 채우면 자동 개선됨(코드 변경 불필요).
- **(기록)** `showOb()` 함수가 바로가기 제거 후 미사용 상태로 남음(첫 실행 온보딩과 무관하므로 보존, 위험 없음).
- **(기록)** 커스텀 테마·글래스·zoom은 `color-mix`/`backdrop-filter`/`zoom` 사용 — 구형 브라우저 폴백은 안전하나 실제 모바일 시각 확인 권장.

## 4. 아직 남아있는 문제 (의도적 보류·범위 외)
- **Grok 게이트 봉인 유지**(`GROK_활성화=false`) — 승인·크레딧 영역. 음성 입력은 Grok과 무관하게 동작.
- **구어 교정 채점** — 현 단계 불필요(지시서 명시). 음성→텍스트 입력 확보까지 구현.
- **sq2 임시 표본 하드코딩** — DB JSON 채워지면 제거. (작업인계_노트·KNOWLEDGE 기록)
- **브라우저 실기기 확인** — 음성 인식 정확도, zoom/글래스 렌더는 실제 모바일에서 추가 확인 권장.

## 5. CI 구성 내용 (`.github/workflows/ci.yml`)
PR/푸시 시 자동 실행, 무료 `ubuntu-latest`만 사용.

**잡 1 — HTML / JS 기본 검증**
1. `node scripts/check-inline-js.mjs` — 인라인 JS 문법(`node --check`)
2. `htmlhint --config .htmlhintrc index.html` — 태그 짝·id 중복·DOCTYPE·title
3. `node scripts/check-deploy.mjs` — 진입점·충돌 마커·골격 태그·GROK 플래그

**잡 2 — 기능 동작 테스트 (jsdom)**
4. `npm ci && npm test` — 학습/커서/음성/글자/복습/커스텀 테마 동작 64건

> 로그는 한국어이며 JS 오류는 index.html 기준 줄 번호를 함께 출력한다. 상세: `docs/CI_가이드.md`.

## 6. Branch Protection 적용 방법 (설명만 — 실제 설정은 관리자 직접)
1. 저장소 **Settings → Branches → Add branch protection rule**
2. 패턴 `main`
3. ✅ Require a pull request before merging
4. ✅ Require status checks to pass → **`HTML / JS 기본 검증`**, **`기능 동작 테스트 (jsdom)`** 둘 다 선택
   - 상태 체크는 CI가 1회 실행된 뒤 목록에 나타남(PR 한 번 올린 뒤 설정)
5. (권장) ✅ Do not allow bypassing
→ 설정 후 CI 실패 시 Merge 버튼 비활성화. 상세: `docs/CI_가이드.md`.
