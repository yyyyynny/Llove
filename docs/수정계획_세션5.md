## 1단계 — 가시성·색 + 등급 통일 (버그 3·4·5)  [위험 낮음]

### 버그 3 — "사고 전개"·채팅 글자가 안 보임
- 원인: 중요한 글을 **보조색 `--txt2`(또는 `--txtm`)**로 칠해 어두운 테마에서 배경에 묻힘. (페이퍼만 밝은 배경이라 보임)
- 수정: 아래 "읽는 글"들의 색을 **기본 글자색 `--txt`**(또는 대비 확보된 값)로 상향.
  - `.obj-note`(이의있음 근거/사고전개 패널, index.html:789) `color:var(--txt2)`→`var(--txt)`
  - `.ask-msg.user`(채팅 내 사용자 말풍선, :688) `--txt2`→`--txt`
  - 질문/사고전개 응답이 렌더되는 말풍선 텍스트 점검 후 동일 상향.
- 검증: 5개 기본 테마 + 커스텀에서 글자가 배경에 안 묻히는지 육안 + 대비 점검.

### 버그 4 — 칭호 글자가 잘 안 보임(색이 너무 쎔)
- 원인: 칭호 색이 **테마와 무관한 고정 색표**(`소칭호색상표`, :1936)라 일부 배경에선 묻히거나 튐. 현황 탭은 JS 인라인 색이 CSS를 덮어써(대비 조정 불가).
- 수정:
  - 색표를 **명도 올린 값**으로 조정 + 어떤 배경에서도 또렷하도록 **얇은 외곽선/그림자**(`text-shadow` 또는 `-webkit-text-stroke`) 부여.
  - 기본 폴백을 `var(--accl)`/`var(--txt)`로. 창조주 황금(`#ffd700`)·주신 글리치 효과는 유지.
  - 대상: `소칭호적용()`(:1942), `.status-sub-title`(:527), 성장상세 칭호 span(:6151).

### 버그 5 — 강림자 표시 불일치(현황엔 뜨고 성장상세엔 없음)
- 사실 확인(설명용): **강림자 = Lv.70 등급. 정식 설계(α13, KNOWLEDGE:471). 계정·임의추가 아님.**
- 원인: `렌더_성장상세()`(:6124)가 `등급정보()`를 호출하지 않아 등급 칸이 없음(현황 `ss`는 호출함).
- 수정: 성장상세에서 `등급정보(표시Lv)` 호출 → 현황과 **동일하게 "등급·세부" 표시**. 로드맵 Lv.70 칸도 등급 명시.

## 2단계 — 글자 크기 / 화면 크기 분리 (버그 1)  [위험 중]

- 원인: 현재 "글자 크기"가 `document.documentElement.style.zoom`(:5545)이라 **UI 전체**가 확대됨.
- 수정 — **두 개의 독립 조절로 분리**:
  1. **「화면 크기」** = 기존 zoom 그대로(라벨만 변경). 저장키 **`plx_화면배율`**(신규) + Firestore `화면배율`.
  2. **「글자 크기」** = **읽는 글자만** 커지는 새 배율. CSS 변수 `--글자배율`(:root, 기본 1) 도입 →
     학습 콘텐츠 텍스트(문제·선택지·플래시카드 앞뒤·뜻풀이·채팅/사고전개·구어 예문 등) 규칙에
     `font-size:calc(<기존>px * var(--글자배율))` 적용. **앱 틀(네비·아이콘)은 안 키움**(의도된 UX).
     저장키 **`plx_글자배율`**(기존 키 재사용 — 의미만 zoom→글자배율, 둘 다 기본 100이라 자연 호환) + Firestore `글자배율`.
- 설정 화면에 조절 UI 2개(각 단계 버튼) + 저장·복원(초기 로드 `plx_*`, 로그인 시 Firestore).
- 주의: 기존 `plx_글자배율`(과거 zoom%) 값은 이제 글자 배율로 적용됨 — 영향 미미(같은 %, 기본100). 주석에 명시.

## 3단계 — 학습 설정: 적용·저장·애니 (버그 7·8)  [위험 중~높음]

### 버그 7 — "직접 입력" 선택해도 적용 안 됨 + 설정 미저장
- 원인:
  1. `setLsetMode()`(:3975)가 sq1/sq3/sq4_input에서 값만 저장하고 **화면을 다시 안 그림**(토스트만).
  2. 출제 함수(`renderQuiz4`:3186 / `renderQuiz3`:3210 / `renderDad`:3747)가 `학습설정` 값을 **안 봄**.
  3. `학습설정`이 **localStorage에 저장 안 됨** → 새로고침 시 기본값으로 복귀.
- 수정:
  - `setLsetMode()`에서 모드 변경 후 해당 출제 함수 **재호출**(현재 풀로 다시 그림).
  - 출제 함수에 **`직접입력` 분기 구현**: 선택지 대신 **답 타이핑 입력칸 + 정답 비교**(정답/오답 처리는 기존 `selAns` 흐름 재사용). 아재개그(sq4)는 "직접입력"이 의미상 맞는지 확인 후 적용 범위 결정(부적합하면 해당 옵션만 정리).
  - `학습설정` → **`plx_학습설정` 저장 + 초기 복원** 추가.
- 검증: 직접입력 선택 → 입력칸 등장 → 정답/오답 판정 → 새로고침 후 설정 유지 (jsdom 테스트).

### 버그 8 — 학습 설정 패널 펼침/접힘 부자연
- 원인: `.lset-body`(:300)가 높이(max-height)만 애니하고 **여백(padding)이 동시에 튀어** 접힘이 끊김. 펼침 첫 프레임 누락 가능.
- 수정: 높이 + **여백 + 투명도(opacity)를 함께** 부드럽게(또는 `transform: translateY` 수직 = fadeUp 계열, 규칙 준수). 토글 화살표는 **회전(rotate) 대신 ▼/▲ 글자 교체**(회전 금지 규칙 준수).
- 검증: 펼침/접힘 모두 자연스러운 수직 전개. (jsdom은 클래스 토글만 검증)

## 4단계 — idle 커서 깜빡임 (버그 9)  [위험 낮음]

- 원인: 일부 입력창이 **숨겨진 뒤에도 포커스를 유지**해 네이티브 커서가 계속 깜빡임. `focus()` 호출마다 짝이 되는 `blur` 누락(예: 이름변경 모달 `nmModalInp` :2387 등).
- 수정: 모든 입력 `focus()` 지점에 대응하는 닫기 함수에서 `활성입력_blur()` 호출 보장 +
  화면 전환·모달/패널 닫힘 시 활성 입력 blur(안전망). 깜빡이는 실제 입력창 특정 후 처리.
- 검증: 입력 후 패널 닫고 가만히 둘 때 활성요소가 body/버튼이 되는지 (jsdom 테스트).
