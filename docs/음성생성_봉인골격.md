# 콜롬비나 음성 생성(TTS) — 창조주 전용 봉인 골격

> 작성: Claude Code 세션 (브랜치 `claude/stoic-newton-bcn8rb`)
> 상태: **봉인 골격 완료** — 서버·끝말잇기 준비 후 플래그만 켜면 연결.

---

## 1. 왜 / 무엇

최고 관리자님이 로컬에서 So-VITS로 학습시킨 **콜롬비나 음성 TTS**(텍스트→3~8초→음성)를
Llove로 가져오기 위한 골격. 원래 목적은 **끝말잇기에서 단어를 그 목소리로 말하기**.

- **RVC 실시간 변조는 제외** (브라우저 불가, 원래도 미흡). TTS만 채택.
- **끝말잇기 게임은 아직 없음** — 다른 세션에서 완성 후 제공 예정. 도착하면
  `음성생성호출(단어)` 한 줄로 연결.

## 2. 올바른 구조 (중요)

```
[Llove(브라우저)]  --텍스트-->  [외부 GPU 서버: 파이썬 So-VITS]  --음성(wav/mp3)-->  [Llove가 재생]
```

- 파이썬 모델은 **외부 GPU 서버에서** 돈다. 브라우저·끝사용자 기기에선 **절대 안 돈다**
  (파이토치+CUDA 필요). Llove는 텍스트를 보내고 **완성된 음성만 받아 재생**한다.
- 서버 위치: 성능 남으면 **본인 PC(RTX4060)+터널(Cloudflare Tunnel 등)**, 아니면
  **유료 클라우드 GPU**. ※ **AWS 프리티어엔 GPU 없음** — 무료 GPU 상시 서버는 사실상 없음.
  Runpod/Vast.ai가 AWS보다 저렴.
- 비밀키는 프론트·레포에 두지 않음 — 서버 또는 Cloudflare Worker에서만 관리(Grok과 동일).

## 3. 이번에 구현된 것 (index.html, 봉인 상태)

Grok 봉인 패턴(`GROK_활성화`)을 그대로 복제.

| 요소 | 이름 | 설명 |
|---|---|---|
| 봉인 플래그 | `const 음성생성_활성화 = false` | ⚠️ 승인 없이 true 금지. 서버 준비 후에만. |
| 호출 함수 | `음성생성호출(텍스트)` | 봉인/미설정 시 fetch 없이 `null`. 활성 시 POST→음성 Blob. |
| 재생 | `음성재생(소스)` | `new Audio()` (프로젝트 최초 오디오 재생 인프라). Blob/URL 모두 허용. |
| 로딩 UI | `음성생성_로딩(켜기)` | "🎙 음성 생성 중…" — **회전 금지 규칙 준수**(점 불투명도 펄스, `@keyframes pulse`). |
| 창조주 게이트 | `갱신_음성설정_UI()` / `음성설정_탭()` | 설정 화면 `#음성설정Row` — 창조주만 노출. 비창조주는 행 숨김+안내 모달. |
| 테스트 벤치 | `#음성생성Bg` 모달, `음성_테스트생성()` | 엔드포인트 입력 + 문장 입력 + [생성·재생]. 봉인 중엔 안내만. |
| 엔드포인트 영속 | `음성엔드포인트_저장/지우기` | `plx_음성엔드포인트`(localStorage) + Firestore `음성엔드포인트`. **코드에 주소 비저장.** |

- 신규 사용자 기본값 `음성엔드포인트: ''`, `사용자데이터_적용`·초기 로드에서 복원.
- `.gitignore`에 모델·음성 파일 커밋 차단 가드 추가(`*.pth`/`*.onnx`/`*.wav`/`/models/` 등).

## 4. 나중에 할 일 (인프라 의존 — 이번 범위 밖)

1. 파이썬 So-VITS 추론을 작은 HTTP API로 감싸기(FastAPI/Flask): `POST {텍스트}` → wav/mp3.
2. 서버를 로컬 터널 또는 클라우드 GPU에 띄우고, **창조주가 설정 패널에 그 주소 입력**.
3. (권장) CORS·토큰 숨김 위해 Cloudflare Worker로 프록시(Grok Worker처럼).
4. 서버 검증 끝나면 **최고 관리자님 승인 후** `음성생성_활성화 = true`.
5. 끝말잇기 게임 도착 시 단어 출제부에서 `음성재생(await 음성생성호출(단어))` 연결.

## 5. 저작권/안전 전제

콜롬비나 = 호요버스 캐릭터 + 성우 목소리. **공개 배포 위험.**
**창조주 전용·비공개·모델 레포 미포함**이 전제. 코드/주석에 상업·공개 배포 표현 금지.
