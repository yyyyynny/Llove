# 프로필 이미지 — 출처 표기 및 삭제 정책

> 이 폴더의 이미지는 Llove 앱의 프로필 프리셋으로 사용됩니다.
> 앱에 노출하려면 이미지 파일을 이 폴더에 넣고 `목록.json`의 `items`에 등록하세요.

## 정책 (최고 관리자 확정)

1. 모든 이미지는 아래 표에 **출처를 명확히 표기**합니다.
2. **저작권자가 삭제를 요청하면 반드시 삭제합니다.**
3. 본 저장소는 비상업 개인 학습 프로젝트이며, 이미지로 어떠한 수익도 얻지 않습니다.

## 등록 방법

1. 이미지 파일을 이 폴더(`assets/프로필/`)에 추가
2. `목록.json`의 `items` 배열에 한 줄 추가:
   ```json
   { "파일": "예시.jpg", "이름": "표시 이름", "출처": "원작자/출처 URL" }
   ```
3. 아래 출처 표에도 같은 내용 기재

## 출처 표

|---|---|---|---|
